# App Radar status model

## Verified live baseline

Baseline release verified live on merged `main` commit `ff2a645974ac3d74d6c621e1dc761eff67ba4ed9`.

`OFFICIAL / ECOSYSTEM RESOURCE` means a current primary Pi source references the resource. It is not a PioneerHub recommendation, security endorsement or review.

`PIONEERHUB TESTED` may be used only after a dated record covering discover, open, auth where safe, core function, payment only where safe/Testnet-compatible, security, UX, return value and limitations. No real payment is made to an insufficiently understood app.

`NOT YET TESTED` is the default for researched third-party apps. No PioneerHub score or verdict is assigned in this state.

The current `feature/app-radar-test-records` branch adds the first dated test records on top of that verified live baseline.
