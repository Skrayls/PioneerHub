# PioneerHub Lithuania

Independent, community-first education and utility platform for people using the Pi Network.

## Current status

Stage 0 — Foundation, active. The public-information Core prototype is in `app/` and is deliberately non-custodial: it has no wallet connection, payment flow, referral capture, KYC collection, or user database.

## Run locally

```bash
npx serve app
```

## Operating documents

The root Markdown files are the persistent operating state. `MASTER.md` is the controlling strategic specification; supporting evidence is in `research/`.
